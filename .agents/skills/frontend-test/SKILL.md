# 项目内前端验证

根据任务自行选择工具、测试场景、数据规模和取证方式。需要真实 WebView2、用户数据或本地协议时，参考 [cdp 技能](../cdp/SKILL.md)。

## 测试目录

- 测试脚本、fixture、浏览器 profile、缓存和运行产物统一放在项目根目录的 `.local/frontend-tests/`，该目录已被 Git 和 Biome 忽略。
- 复用固定的 profile、缓存和当前任务的环境；不要为每次重试创建新目录或向系统 Temp 写新的测试 profile。
- 复用真实项目代码与依赖，按场景重置测试状态。模拟写入操作使用隔离数据，遵循当前会话对真实数据操作的授权范围。

## 测试结束

- 无论通过、失败还是中断，都关闭本次任务启动或明确接管的测试浏览器与服务，并确认相关子进程退出。关闭失败时核对 PID、启动时间和完整 profile 路径后定向回收。
- 保留用户正在使用的应用、普通浏览器与其他任务的环境；结束真实应用采集时，只移除本次探针和监听器。
- 清理不再需要的临时脚本与产物；可保留一份固定 profile 和缓存供后续复用，报告残留资源的位置。
- 删除前确认绝对目标路径位于测试目录内，使用 `Remove-Item -LiteralPath`。无法确认归属或清理失败时明确报告，不继续堆积新环境。
